This is a working test of Nick Cammarata's claim that LLM neurons are already clean, run on Prism ML's 1-bit and ternary Bonsai models. The extension: read each neuron forwards (what inputs fire it) and backwards (which antecedents an inverse solver needs to drive it to a target).

Finding 1

First neuron readings: most Bonsai poles have one job

We picked 12 neurons at random from layers 8–28 of the 1-bit model and read the top ten corpus examples for each pole. Most poles have one recognizable job, often the same job across several languages. Examples: a neuron for the word "nerve" in English, German, Korean and Arabic; an afterlife neuron firing on "heaven", "Paradise" and the Arabic "this world and the hereafter"; and a "genre" neuron whose opposite pole, unrelated, fires on refuelling at gas stations. The essay treats the two poles of a neuron as separate units, and in this sample they usually hold related jobs.

Reading backwards. For each pole's strongest example, we find the 24 upstream neurons with the largest causal attribution, then give each one a gain from 0 to 1. Three questions follow.

  • How much of the activation do those 24 neurons carry?
  • Can a solver set the gains to land the activation at a requested fraction? This is the round trip.
  • What is the smallest set of upstream neurons that keeps half the activation?

Where a few upstream neurons carry a pole, we read those neurons' own top examples. That chains the backward view back into the forward view. Four such chains are shown in the cards. In the "genre" pole, spelling routes (the token "genre", the subword "gener-") meet a meaning route (literary forms). In the printf pole, every key input is itself a format-string feature.

Two lessons from the pilot

Backward analysis must sample each branch. The strongest example of the "best" pole turned out to be its "all … in common" offshoot, so the inverse described the offshoot's route rather than the main job. The next screen will run the inverse on examples from each cluster of the forward view.

Our route-sharing metric is too strict. Comparing raw attribution vectors over all 442k upstream neurons, even clearly one-concept poles show their 8 top examples as 8 separate routes (median top-24 overlap about 5%). That is more likely a measurement problem than a finding. Grouping upstream neurons into labelled bundles first, as the essay does, should fix it.

Finding 2

Quantization-aware training keeps the base model's neurons

We ran the same 12,288 tokens through all three models and correlated every neuron with every neuron of the same layer in another model. When a neuron's best match carries the same index, Bonsai's 1-bit training kept that neuron in place. If so, the 16-bit, ternary and 1-bit versions of a neuron can be compared directly, which makes the precision ladder a paired experiment.

Perplexity on the same 1,024-token passage of the essay. Same-index Pearson r is moderate (median 0.25–0.54), because the bulk of weak activations dominates it. The next metric to measure is overlap in the strong-activation tail, which is what neuron audits look at.

Method

Reading a neuron backwards

A Qwen3 MLP neuron computes a = silu(g)·u, with g and u both linear in the normalized residual stream. Each step back along the chain of antecedents has a different mathematical structure, so each needs a different solver. The inverse is only as convincing as the round trip: ask for a target activation, apply the solution, and measure what you actually get.

Budget rule

Bulk screening of many neurons runs on the local SciPy/torch toolchain only. globalMOO is reserved for 2–4 carefully chosen neurons, one well-posed problem at a time, trained once and queried for many targets. Each run gets a written hypothesis beforehand.

Finding 3

Each solver earns its place on a different kind of query

This calibration toy is a single SwiGLU neuron with 8 inputs, so it is not a model result. It shows the solvers' characters before we spend any runs on real neurons. globalMOO's learned inverse hits targets inside its trained envelope in a handful of evaluations, but does not extrapolate beyond it. Gradient least-squares is fast whenever the map is differentiable. Differential evolution is robust and expensive.
